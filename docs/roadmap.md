# Roadmap and public checkpoint

Capability Lab's first architecture cycle is now intentionally bounded.

## Completed architecture cycle

```text
PR0–PR9
shared semantics
+ epistemics
+ state
+ history
+ advisory progression
+ first read model

PR10–PR11
Pilot governance
+ immutable persistence
+ complete-history derivation
+ state acceptance
+ governed current selection
+ current-state progression/read composition

PR12.0–PR12.14
generic external observation
→ reviewed evidence
→ governed interpretation
→ governed evaluation
→ governed current state
→ governed product/read snapshot
```

PR12.13 and PR12.14 provide the executable end-to-end integration proofs for the generic path.

## PR12.15 — public reference checkpoint

PR12.15 packages the completed architecture as a polished public reference:

- curated documentation product;
- stable consumer/read-boundary explanation;
- reproducible Zensical build;
- documentation contract tests;
- GitHub Pages workflow;
- preserved normative and research history.

It adds no new inference semantics or authority.

## Development pause

After the PR12.15 checkpoint, Capability Lab enters a **stable research-subsystem pause**.

Future work should be demand-driven by a real consumer or by evidence that an existing contract is insufficient,
rather than by extending the PR sequence for its own sake.

Potential future work is explicitly *not* pre-authorized:

```text
automatic closed-loop capability updates
reduced-review write paths
new scoring / ranking semantics
permission or professional-authority coupling
```

Any such direction requires a new source-of-truth issue and a fresh authority/safety review.

## Historical note

The project began with a Civilization Bootstrap / Technical Generalist stress test. That lineage remains preserved
under `docs/domains/`, `docs/pilots/`, and `docs/legacy/`, while the current generic architecture is documented
through the curated portal and PR12 executable audits.
