## Civilization Bootstrap research lineage

Capability Lab began with a Civilization Bootstrap / Technical Generalist domain as a demanding stress test.
That domain and the first private-workspace Pilot remain preserved, but the generic PR12 path is deliberately
independent of the Pilot-specific production path.

- [Civilization Bootstrap domain](../domains/civilization_bootstrap.md)

governance model was hardened. They are reference material, not the recommended first reading path.
